My project name is 🛒 বাজার দর (BazarDor)

Description:- 
বাজার দর is a responsive web application that helps users explore essential daily products and compare their prices across different markets in Bangladesh.

🛠️ Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- HeroUI
- Better Auth
- Mongodb
- React toastify 


## ✨ Key Features
1. Browse products by category.
2. View detailed product information and prices.
3. Compare prices across different markets.
4. Sort products by price.
5. User authentication with email and Google sign-in.
